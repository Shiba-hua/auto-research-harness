## 一句话概括

> 在单卡 L40S 上部署一个 harness，它能**读懂 codex 留下的任务书与仓库现状，自己推断出未竟之事并跑完**，把过程与结果推到 GitHub 新分支。实验占用 GPU 期间 harness 降档运行，靠一个常驻的「值班员」保证永远有人应答。

## 关键实测数字

| 项 | 值 |
|---|---|
| **MiniCPM5-2B 最优配置** | IQ4_XS + 12 线程 + f16 KV → **pp512 290 t/s / tg128 37.9 t/s** |
| 累计优化提升 | **3.3 倍**（起点 11.4 t/s） |
| 端到端任务（读 2k 日志 + 写 100 token） | **约 9.5 s** |
| 投机解码上限（合成接受） | **仅 +15%** → 结论：不值得做 |
| OpenVINO | 解码慢 3.4–4.4× → **不可用** |
| 可靠性 | MiniCPM5-2B R1 5/5、R2 3/3；Qwen3.5-0.8B R1 **0/5** |
| 绘图能力专项 | 裸写 matplotlib **823 token / 25.6 s / 一次跑通**；工具调用 **220 token / 7.7 s / 参数全对** → **选工具化**（安全边界） |
