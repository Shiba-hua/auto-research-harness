# DSH 界面验收清单（L40S-2-gpus）

## 0. 打开界面

在**你自己的机器**上开一条 SSH 隧道（我这边已经开好一条，可直接跳到第 2 步）：

```bash
ssh -f -N -L 18080:127.0.0.1:18080 L40S-2-gpus
```

然后在浏览器打开：

```
http://127.0.0.1:18080/?token=WVzNO8yS7D24TkKQv1IJQNZD225Yp6TCAJkRhjo_h0Y
```

> ⚠️ **token 会随 DSH 重启轮换。** 若提示 401，重新取一次：
> ```bash
> ssh L40S-2-gpus 'grep -oE "token=[A-Za-z0-9_-]+" /root/dsh-harness/logs/dsh.log | tail -1'
> ```
>
> ⚠️ DSH 只监听 `127.0.0.1`（这是它的安全设计，不接受 `--host 0.0.0.0`），
> 所以**必须走隧道**，不能直接用外网 IP。

## 2. 验收项

### 区块 1 · 能问答（数字须与实况一致）

在会话里问：

| 提问 | 期望 |
|---|---|
| `现在服务器上有几张 GPU？型号是什么？` | 2 张，NVIDIA L40S |
| `研究员模型的上下文窗口有多大？` | 262144（256k） |
| `值班员现在跑在 CPU 还是 GPU 上？` | GPU 1（可对照 `state/guard-mode`） |

**判据**：数字必须与服务器实况一致，不能是编的。可让值班员调用 `lab_gpu` 工具自查。

### 区块 2 · 能看图

让它画一张图，例如：

```
用 plot_series 画一条正弦曲线，存成 PNG
```

**判据**：图片**内嵌显示在对话里**（不是只给路径），且能打开看到曲线。
（后端已实测 MCP 能返回真 PNG。）

### 区块 3 · 能派活（自主完成 + 主动播报）

派一个小任务，例如：

```
让研究员算一下 1 到 100 的和，并说明用什么方法
```

**判据**：
- 值班员会**自主唤醒研究员**（`researcher` 工具）
- 完成后**主动汇报结果**，不需要你再问一次
- 研究员回复里**不应再出现思维链**（见下方"已修复项"）

### 区块 4 · 能跑真实验并推 GitHub

这条可选，主要看链路是否通：

```
让研究员报告最后一次推测解码实验的加速比
```

**判据**：能说出实测数字（MTP 稳态 1.51×、DFlash2 1.68×、DFlash 1.39×）。

## 3. 安全员验收

刻意触发一次需要审批的操作，例如让它删除一个 lab 里的未跟踪文件，
或写 `/root/siton-tmp/rlvr-l40s-lab/tests/` 下的文件。

**判据**：
- 硬风险（写 `.venv`/`models`/`data`、force push、递归删根）应被**直接拒绝**且不弹人工审批
- 改测试阈值、删未跟踪文件应**弹人工审批**（`ask`）
- 审计记录追加在 `/root/dsh-harness/evidence/approval-gate.jsonl`

无阻塞项。以下为设计取舍，非缺陷：

  如需接入可以加一个 provider。
- **`dsh-approval-gate` 的模型层与人类 answerer 交互未经 UI 验收**：
  确定性策略层已 15/15 单测覆盖，但"灰区 → 模型判可疑 → 弹人工"这条链只有代码级验证。
